## 2. Windows 셋업과 첫 실행

- 필요 도구: Node.js LTS, rustup(MSVC toolchain), **VS 2022 Build Tools의 "C++ 데스크톱 개발"(VCTools) 워크로드**, WebView2 런타임. `winget` 명령은 README의 *Windows* 절에 정리.
- 설치 직후에는 새 터미널을 열어야 `PATH`가 반영됨 → `scripts/dev.ps1`이 레지스트리에서 `PATH`를 다시 읽고 Corepack 다운로드 프롬프트를 끈 뒤 `tauri dev`를 실행.
- Windows에는 `make`가 없음 → `Makefile`을 이식 가능한 형태(rm/cd/`&&` 없음)로 바꾸고, **모든 타깃에 대응하는 루트 `pnpm` 스크립트**를 추가 (`pnpm tauri:dev`, `pnpm check`, `pnpm test:rust`, `pnpm windows-installer` 등).
- `tauri::generate_context!`가 `apps/desktop/dist`를 컴파일 타임에 요구 → `scripts/ensure-dist.mjs`가 없을 때 placeholder 생성 (`pnpm rust:prep`, clippy/test:rust가 자동 호출).
- `pnpm-workspace.yaml`에 `onlyBuiltDependencies` allowlist (pnpm 10의 빌드 스크립트 승인).
- 첫 실행에서 드러난 것: 시드 `admin/admin`으로 바로 앱 전체 사용 가능, hooks가 Windows에서 실행 불가(확장자 없는 스크립트), 창 닫기 시 디바운스 중인 저장이 유실될 수 있음 등 → 아래 감사 항목으로 이어짐.

## 3. 감사 결과 (주요 발견)

| 영역 | 발견 |
|---|---|
| 인증 | 백엔드는 로그인 여부를 확인하지 않았음(UI 숨김이 유일한 장벽). 기본 비밀번호 변경 강제 없음, 비밀번호 변경/계정 생성 IPC 없음, 로그인 시도 제한 없음, 토큰 만료 없음. `auth_log_action`으로 `login_success` 같은 이벤트 위조 가능. |
| 설정 | `app_config_get`이 AI API 키를 렌더러로 그대로 반환. base URL에 평문 `http://` 원격 허용. |
| 경로 | vault 루트 자체를 검증하지 않아 `~`나 `C:\`를 vault로 지정하면 containment가 무의미. IPC로 `.git/` 내부 쓰기 가능(hook 심기). `notes/.` 같은 표기로 `_inbox`/`notes` 루트 삭제 우회 가능. |
| 편집기 | 저장이 직렬화되지 않아 노트 전환 직후 이전 노트 내용이 새 경로로 저장될 수 있음, 늦게 도착한 open 응답이 최신 선택을 덮어씀, 창 닫기 시 미저장 내용 유실, 저장 실패가 조용히 사라짐. |
| 동기화 | 네트워크 단계 동안 vault 락을 잡아 원격이 느리면 저장이 멈춤, 타임아웃 없음, 자격증명 콜백 무한 반복 가능. 충돌 후 재동기화 시 같은 충돌이 반복(수렴하지 않음), 새 vault를 기존 원격에 연결 불가. |
| 노트/FS | 읽기 명령이 동기 Tauri 명령이라 UI 스레드에서 vault 순회. 대소문자만 다른 rename 실패. slug 길이 무제한 + Windows 예약 이름(`CON` 등) 미처리. 제목 YAML 인용이 비대칭이라 줄바꿈/따옴표가 front matter를 깨뜨림. 태그 인덱스 재빌드와 쓰기가 경쟁하면 오래된 스냅샷이 캐시됨. |
| Hooks | Windows에서 확장자 없는 스크립트는 실행 불가, `on-note-save`가 `notes_write`에만 걸림, 실패가 아무 흔적도 남기지 않음. |
| Evernote | `.enex` 전체를 메모리에 로드, 잘못된 엔티티 하나로 노트 전체 실패, import 전체 동안 vault 락 점유(자동 저장 정지), 변환 실패 시 부분 결과가 디스크에 남음, `index.md`라는 첨부가 본문을 덮어쓸 수 있음, 링크 URL 미검증(`javascript:`). |
| 빌드/CI | Windows CI 없음, action 태그 미고정, Rust 버전 미고정(rustfmt 결과 흔들림), 오래된 의존성. |

## 4. 영역별 수정

### 인증 / 세션 (백엔드 + 프론트)

- **세션 게이트**: `services/session.rs`의 `ActiveSession` — `auth_login`/`auth_resume`/`auth_logout`을 제외한 모든 명령의 첫 문장이 `require_session(&active)?`. `lib.rs`의 `every_registered_command_is_gated` 테스트가 `generate_handler!` 목록을 파싱해 강제.
- `auth_change_password`, `auth_create_user` 추가. `LoginResult.mustChangePassword` → `LoginScreen`에서 강제 변경 단계. 5회 실패 시 5분 잠금, 존재하지 않는 사용자도 Argon2 1회 수행(타이밍 균등화), 12시간 유휴 / 7일 절대 만료.
- `auth_log_action` 허용 목록, `AppConfigView`(`ai.hasApiKey`만 노출, 키는 쓰기 전용), base URL 규칙(https 또는 loopback http).
- `services/vault_path.rs`: vault 루트 검증(절대·정규 경로, 루트/홈/시스템·앱데이터 위치 거부). 모든 rel path에서 `.git` 거부.
- 프론트: `lib/api/invoke.ts` 중앙 래퍼 — 비-auth 명령의 `Unauthorized` → 저장 flush 후 로그아웃 + "session ended" 안내. 계정/감사 로그/비밀번호 폼을 `features/auth/`의 공용 컴포넌트로 분리해 `/admin` 대시보드와 설정 모달이 공유.

### 편집기 저장

- `state/autosave.ts`: 문서별 pending save(대상 경로·vault를 편집 시점에 캡처), 쓰기 직렬화, 실제로 쓴 텍스트만 saved 처리, 실패 시 `saveError` 표시 + 백오프 재시도, `flushPendingSave`.
- `lib/openDocument.ts`: 열기 전 flush + latest-request-wins. `lib/journalPath.ts`(저널 경로 단일 소스), `state/vaultContentStore.ts`(파일 변경 카운터로 목록 패널 갱신), `editorStore`의 `revision`/`saveError`.
- 창 닫기 시 flush 후 `destroy` (capability `core:window:allow-destroy` 추가). `EditorPanel` lazy-load. 설정 모달을 `features/settings/sections/*`로 분할, `useDialogFocus`로 포커스 트랩 등 접근성 보강.

### 동기화

- `services/git.rs`를 prepare(락) / fetch(무락) / integrate(락) / push(무락) 단계로 분리, 프로세스 전역 sync gate로 직렬화.
- 충돌 시 pending merge를 `.naiteh/sync-state.json`에 저장, sidecar가 모두 해결되면 머지 커밋 기록 → 충돌이 수렴. `SyncStatus.mergePending` 추가.
- 기존 원격 합류(`naiteh: join existing vault`), fetch/push 300초 데드라인 + 연결/읽기 타임아웃, 자격증명 방식별 1회 시도.

### 노트 / 파일시스템

- `normalize_rel_path`(정규형 아니면 거부), `resolve_notes_subdir`(폴더 명령), 대소문자만 다른 rename 허용.
- `slugify` 80자 제한 + Windows 예약 이름 회피(`con` → `con-note`), `yaml_quote`/`parse_scalar` 대칭 인용.
- 읽기 명령 전부 async + `fsx::run_blocking`. `search_text`는 인덱스의 파일 목록/제목을 쓰고 내용만 읽음. 태그 인덱스에 generation 카운터.

### Hooks / Evernote

- Hooks: Windows에서 `.exe` → `.cmd` → `.bat` → `.ps1` 순서 탐색(cmd /C, powershell -File), 콘솔 창 숨김. `on-note-save`가 write/create/rename(새 경로)/set-pinned 후 실행. 실패/타임아웃은 stderr에 기록.
- Evernote: 스트리밍 `EnexReader`, 관대한 엔티티 처리, 노트 단위 락, 변환 실패 시 아무것도 쓰지 않음(쓰기 실패 시 폴더 롤백), `sanitize_url`, `index.md` 첨부 이름 변경.

### 빌드 / CI

- CI: guards + frontend + Rust(Linux/macOS/Windows) + 각 OS 디버그 번들, action SHA 고정, Rust 1.90.0 고정.
- `Cargo.toml`: `rust-version = "1.90"`, `reqwest` 0.13 / `thiserror` 2 / `dirs` 6. `tauri.conf.json` 번들 메타데이터. `prompt/` 디렉터리 삭제, README 재작성.

## 7. 작업 시 참고할 패턴

- Windows에서는 `make` 대신 루트 `pnpm` 스크립트 (`pnpm check` = CI와 동일).
